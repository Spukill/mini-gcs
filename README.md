# mini-gcs

A minimal **Ground Control Station (GCS)** for drones, written in C# / .NET (WPF, MVVM).

It connects to a simulated drone (ArduPilot SITL) over **MAVLink/UDP** and shows real-time telemetry:
position, altitude, speed, battery and flight state.

> Learning project: built step by step to learn the stack used in professional GCS software
> (C#/.NET, WPF/MVVM, async and multi-threading, real-time telemetry, logging, CI/CD).

## Tech stack

| Area | Choice |
|---|---|
| Runtime | .NET 10 (LTS), pinned via `global.json` |
| UI | WPF + MVVM (data binding) |
| Protocol | MAVLink over UDP |
| Simulator | ArduPilot SITL |
| CI | GitHub Actions (build + tests on every push) |

## Project structure

```
mini-gcs/
├── MiniGcs.slnx          # solution (groups all projects)
├── global.json           # pins the .NET SDK version
└── src/
    ├── MiniGcs.App/              # WPF desktop app
    │   ├── Models/               # plain data (Telemetry)
    │   ├── Services/             # data sources (ITelemetrySource, FakeTelemetrySource)
    │   ├── ViewModels/           # screen state + INotifyPropertyChanged (MainViewModel)
    │   └── MainWindow.xaml       # the view, bound to MainViewModel
    ├── MiniGcs.Mavlink/          # MAVLink C# code generated by mavgen (ardupilotmega.xml)
    └── MiniGcs.Sniffer/          # console tool: prints MAVLink heartbeats received over UDP
```

Data flow: `ITelemetrySource` → event `TelemetryReceived` → `MainViewModel` → `PropertyChanged` → WPF bindings update the screen.

## Build and run

Requirements: Windows, [.NET 10 SDK](https://dotnet.microsoft.com/download).

```powershell
dotnet build
dotnet run --project src/MiniGcs.App
```

## Running with ArduPilot SITL

The drone is simulated by [ArduPilot SITL](https://ardupilot.org/dev/docs/sitl-simulator-software-in-the-loop.html)
running in WSL2 (Ubuntu 24.04). MAVProxy forwards its MAVLink telemetry over UDP to Windows on port 14550.

```
ArduPilot SITL ──TCP 5760──▶ MAVProxy ──UDP 14550──▶ mini-gcs (Windows)
```

1. Set up ArduPilot in WSL (once): clone `https://github.com/ArduPilot/ardupilot` with `--recurse-submodules`
   and run `Tools/environment_install/install-prereqs-ubuntu.sh -y`.
2. Start the simulated copter (home point at FEUP, Porto):
   ```bash
   cd ~/ardupilot
   sim_vehicle.py -v ArduCopter --console --map --custom-location=41.1780,-8.5980,120,0
   ```
3. On Windows, print the heartbeats it sends:
   ```powershell
   dotnet run --project src/MiniGcs.Sniffer
   ```
   ```
   [14:32:01] HEARTBEAT de 1:1 | QUADROTOR | DISARMED | STABILIZE | pacotes recebidos: 47
   ```
4. In the MAVProxy prompt, wait for `pre-arm good`, then `mode guided`, `arm throttle`, `takeoff 10`
   and watch the sniffer switch to `ARMED | GUIDED`.
